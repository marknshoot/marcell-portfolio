# Marcell Hermawan Kristianto — portfolio

Internship landing page for AI Engineer (Data Scientist / Data Engineer as adjacent fit).

Facts and copy live in `content/`. What gets served is `site/` (static HTML/CSS/JS — not Next.js).

Local:

```bash
python3 -m http.server 8080 --directory site
```

Vercel: set the project **Root Directory** to `site`, or deploy from that folder.

No resume PDF on v1. English is default; Indonesian is the EN/ID toggle.
